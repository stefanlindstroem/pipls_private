# Decision 0085: self-contained Pulp tutorial

## Status

Accepted and implemented.

## Context

Tutorial 2 had a sound analytical sequence but displayed code fragments from a larger report script.
Imports, constants, response selection, and some axis variables were not defined before use. The
standalone SVG figures were generated by code different from the displayed multi-panel snippets,
and the complete example was expanded again at the end of the page. The three detailed responses
were selected by name without explaining that the choice was only for display readability.

## Decision

Keep Tutorial 2 concise but make its programming sequence self-contained:

- show one setup snippet before data loading;
- select the first three response columns explicitly and state that this is only for legibility;
- keep analysis snippets in `examples/10_pulp_real_data.py`;
- source each standalone interpretation figure from the corresponding marked block in
  `tools/render_pulp_tutorial.py`;
- show direct predictor-direction plotting as well as the biplot and prediction diagnostics;
- explain the default Pulp rank ceiling and the deterministic non-shuffled splitter briefly;
- add concise dataset-specific readings of the displayed figures;
- link to the maintained example instead of embedding its complete source.

The complete numbered example retains its six PDF outputs and broader report composition. The
tutorial renderer retains seven single-chart SVG outputs.

## Consequences

- Every variable used by the tutorial snippets is introduced before use.
- Each displayed interpretation figure is generated by the displayed standalone plotting recipe.
- The tutorial remains shorter in rendered form because the full example source is no longer
  embedded.
- The first-three-response subset carries no scientific selection claim; it is only a visibility
  choice for the pointwise demonstration.
- Tutorial ownership remains split between the maintained analysis example and deterministic
  single-chart renderer rather than a hidden workflow helper.
